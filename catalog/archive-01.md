## A-001 · 基于Django+Spark的医药数据分析系统的设计与实现

**技术方向：** Django / Spark  
**材料概况：** 功能说明 / 论文相关材料（领取前确认授权与脱敏）

### 项目简介

本系统以 **Django + Vue 2.x + MySQL 8.0** 为技术栈，目标是构建一套“角色清晰、流程完整、数据可查”的医药数据分析系统，具体目标包括：
- 为管理员提供分析、用户、配置、商品、Pages、公共等后台管理能力，保证基础数据可维护、业务记录可追溯；
- 为普通用户提供分析、用户、配置、商品、Pages等前台功能，覆盖从进入到办结的完整链路；
- 以 5 张数据表承载业务实体，保证comment_trend、config、jd_goods、jd_goods_commit之间的关联关系在数据库层面有明确约束；
- 对外提供 97 个接口，前后端通过统一的响应结构（JSON）交互，降低联调成本；
- 功能范围覆盖：评论数据爬取、脏数据清洗、HDFS 分布式存储、PySpark 多维度统计、销售趋势分析、品类市场份额；
- 通过统计接口与图表组件把业务数据转化为可视化指标，支撑管理决策；
- 在部署上只依赖 Python 运行环境与 MySQL，不引入 Redis、消息队列等中间件，保证在单机上可完整运行。

### 功能要点

- 评论数据爬取、脏数据清洗、HDFS 分布式存储、PySpark 多维度统计、销售趋势分析、品类市场份额
